# PhoneMirror LAN

Локальное приложение для своего телефона (или с явного согласия владельца):
транслирует экран, камеру и микрофон на ПК в одной Wi‑Fi сети и позволяет
включать звуки на телефоне с ПК.

## Что важно

- Приложение не скрывается: на телефоне постоянно видно уведомление
  с токеном и кнопкой «Остановить».
- Захват экрана начинается только после системного диалога Android.
- Микрофон и камера включаются только после разрешений Android.
- Сервер слушает `0.0.0.0:8080` только в локальной сети. **Не пробрасывайте этот порт
  в интернет.**

## Запуск

1. Откройте папку `PhoneMirrorLAN` в Android Studio (нужна Android Studio Electric Eel или новее, JDK 17).
2. Подключите телефон по USB, включите отладку по USB.
3. Нажмите Run → приложение установится на телефон.
4. В приложении:
   - разрешите камеру/микрофон/уведомления;
   - нажмите **«1. Разрешить захват экрана»** и подтвердите системный диалог;
   - нажмите **«2. Запустить трансляцию»**.
5. На ПК в браузере откройте адрес, показанный в приложении/уведомлении:
   `http://<IP-телефона>:8080/`
6. На странице:
   - два окна — экран и камера;
   - кнопка **«Включить звук в браузере»** — чтобы услышать микрофон;
   - кнопки `beep`, `alarm`, `chime`, `siren` — включают звук на телефоне;
   - **«Остановить трансляцию»** — выключает сервис.

## Структура

- `MainActivity.kt` — разрешения и запуск сервиса.
- `StreamService.kt` — foreground-сервис, держит всё вместе.
- `ScreenCapturer.kt` — MediaProjection → JPEG-кадры.
- `CameraCapturer.kt` — Camera2 → JPEG-кадры.
- `MicCapturer.kt` — AudioRecord → PCM-чанки.
- `SoundPlayer.kt` — генерация звуков через AudioTrack.
- `WebServer.kt` — Ktor: HTTP/MJPEG + WebSocket + веб-пульт.

## Ограничения прототипа

- Видео идёт как MJPEG — задержка и нагрузка зависят от телефона и Wi‑Fi.
  Для продакшена обычно используют WebRTC.
- Микрофон передаётся как сырой PCM по WebSocket; браузер требует нажатия
  «Включить звук в браузере» из-за политики автозапуска аудио.
- Токен в URL — просто защита от случайного подключения в LAN, не полноценная
  аутентификация. Не используйте это для доступа через интернет.
