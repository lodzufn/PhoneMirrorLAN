# Как получить APK-файл

APK нельзя собрать в чате: здесь нет JDK и Android SDK. Ниже два способа получить файл,
оба **без USB-кабеля**.

## Вариант 1 — облачная сборка, просто скачать файл

1. Создайте репозиторий на GitHub.
2. Загрузите в него всё содержимое папки `PhoneMirrorLAN`
   (вместе с папкой `.github`).
3. Откройте вкладку **Actions** → выберите **Build APK** → **Run workflow**.
4. Дождитесь окончания задачи.
5. Внизу страницы задачи скачайте артефакт **phone-mirror-apk**.
6. Распакуйте архив — внутри будет `app-debug.apk`.

## Вариант 2 — собрать локально в Android Studio

1. Установите Android Studio, откройте папку `PhoneMirrorLAN`.
2. В меню: **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
3. Готовый файл:
   `PhoneMirrorLAN/app/build/outputs/apk/debug/app-debug.apk`

## Как поставить APK на телефон без USB

1. Перекиньте `app-debug.apk` на телефон любым способом: Telegram, почта,
   облако, карта памяти.
2. Откройте файл на телефоне.
3. Разрешите установку из неизвестных источников (Android спросит сам).
4. Установите. Откройте приложение и дайте разрешения.

Дальше в приложении: «Разрешить захват экрана» → «Запустить трансляцию» →
на ПК в браузере открыть `http://<IP телефона>:8080/`.
